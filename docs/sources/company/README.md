# docs/sources/company/

Cartella per i documenti **aziendali** da indicizzare nel RAG layer: codice etico,
policy interne di AI governance, linee guida di sicurezza, ecc.

**Il contenuto di questa cartella non è versionato** (vedi `.gitignore`): questi documenti
sono tipicamente riservati e specifici dell'organizzazione che esegue l'assessment.

Formati supportati: PDF, DOCX, TXT, MD. Dopo averli copiati qui:

```bash
aipaf rag ingest
aipaf rag status
```
